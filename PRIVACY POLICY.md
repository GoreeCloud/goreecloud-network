# Privacy Policy — Development Source

This repository currently implements only local Development status/discovery behavior.

The bootstrap server does not implement user accounts, device enrollment, tunnel traffic inspection, analytics, advertising, behavioral tracking, or production telemetry.

Development HTTP request logs are limited to process-level operational output produced by the local server and must not be treated as an approved production logging design.

Future collection, access, processing, sharing, retention, export, deletion, diagnostics, and support-evidence behavior must be governed by the applicable Privacy Shield contracts before production use.

This repository file is an implementation-facing privacy record, not a substitute for any externally required legal privacy notice.
