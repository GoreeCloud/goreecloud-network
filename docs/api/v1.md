# GoreeCloud Network API v1

**Lifecycle:** Development

The v1 API currently exposes only Development control-plane discovery and decision primitives. It is not a production administration or tunnel-control API.

## Implemented Development endpoints

- `GET /healthz` — process health.
- `GET /api/v1/status` — product version, lifecycle, and surface implementation state.
- `GET /api/v1/overview` — current in-memory device/resource/policy counts plus policy, persistence, and authentication state.
- `GET /api/v1/devices` — read-only device inventory. The default Development server starts with an empty inventory.
- `POST /api/v1/access/evaluate` — decision-only access evaluation. Requests require `principalId` and `resourceId`; `deviceId` is optional. The evaluator permits access only when an explicit in-memory allow policy matches and otherwise denies by default.
- `GET /api/v1/platform-systems` — declared Integral Platform System implementation/evidence states.
- `GET /api/v1/capabilities` — machine-readable capability truth table.

## Important boundaries

`POST /api/v1/access/evaluate` does **not** enforce packet flow or tunnel reachability. It returns `enforcement: decision_only` until a verified network enforcement point consumes the decision.

The current control-plane state is volatile process memory. Production persistence, authenticated administration, enrollment/key issuance, tunnel lifecycle, private routing, relay, obfuscation, posture enforcement, and validated Integral Platform System adapters remain unimplemented.
