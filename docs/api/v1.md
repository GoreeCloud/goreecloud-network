# GoreeCloud Network API v1

**Lifecycle:** Development

The v1 API currently exposes Development control-plane discovery, persistence metadata, and decision primitives. It is not a production administration or tunnel-control API.

## Implemented Development endpoints

- `GET /healthz` — process health.
- `GET /api/v1/status` — product version, lifecycle, and surface implementation state.
- `GET /api/v1/overview` — current device/resource/policy counts plus policy, persistence, schema, revision, migration, integrity, and authentication state.
- `GET /api/v1/storage` — read-only Development store metadata. It never returns state-file contents or secrets.
- `GET /api/v1/devices` — read-only device inventory restored from the Development store during normal server startup.
- `POST /api/v1/access/evaluate` — decision-only access evaluation. Requests require `principalId` and `resourceId`; `deviceId` is optional. The evaluator permits access only when an explicit loaded allow policy matches and otherwise denies by default.
- `GET /api/v1/platform-systems` — declared Integral Platform System implementation/evidence states.
- `GET /api/v1/capabilities` — machine-readable capability truth table.

## Persistence behavior

Normal Development server startup uses a revisioned schema-v1 JSON state envelope at `var/network-state.json`, configurable through `GOREECLOUD_NETWORK_DATA_FILE`.

The file-store implementation provides:

- deterministic snapshot ordering;
- monotonically increasing local revisions;
- schema versioning and migration ledger;
- a tested legacy-unversioned-to-v1 migration;
- SHA-256 integrity verification;
- atomic same-directory replacement;
- fail-closed startup for unsupported schema, malformed content, invalid restored state, or checksum mismatch.

This is not a production database, HA store, backup system, Everkeep integration, or multi-writer transaction engine.

## Important boundaries

`POST /api/v1/access/evaluate` does **not** enforce packet flow or tunnel reachability. It returns `enforcement: decision_only` until a verified network enforcement point consumes the decision.

Authentication remains `not_implemented`, so no network-accessible mutating administrative API is provided. Device enrollment/key issuance, production policy administration, tunnel lifecycle, private routing, relay, obfuscation, posture enforcement, and validated Integral Platform System adapters remain unimplemented.
