# API v1 Bootstrap

Base path: `/api/v1`

- `GET /status` returns product version, lifecycle, and source-surface implementation states.
- `GET /platform-systems` returns all seven Integral Platform Systems with current implementation/evidence state.
- `GET /capabilities` returns Network capability IDs and current availability.

Future mutating endpoints must define authenticated actor/authority context, authorization evidence, concurrency/idempotency semantics, input validation, Privacy Shield authorization/minimization, audit correlation, recovery/revision semantics, and stable machine-actionable error codes.
