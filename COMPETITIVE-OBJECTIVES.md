# Competitive Objectives

GoreeCloud Network should ultimately combine the strongest useful characteristics of modern mesh VPN and Zero Trust network-access systems while improving GoreeCloud ownership, self-hosting, explainability, privacy control, recovery, and cross-platform consistency.

Development objectives:

- First-party control-plane and client behavior.
- Self-hosted-first operation without a mandatory vendor control plane.
- Clear direct/relay/obfuscated connection evidence.
- Deny-by-default, explainable access decisions.
- Native Android, Google TV, iOS, Web, and Server experiences.
- Local-first and privacy-minimized diagnostics.
- Recovery-aware configuration changes and migrations.

No competitive parity or superiority claim is established by the current bootstrap.
